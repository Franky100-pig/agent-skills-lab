# llm-context/

Skills about **managing LLM context effectively** — how you structure prompts,
memory, and agent instructions to get reliable output.

Good fits for this category:

- Prompt templates that solved a recurring problem (e.g. "stop the agent from
  burying the answer" — see the `i-have-adhd` skill for inspiration)
- Context-window strategies (what to include, what to summarize, what to drop)
- Memory / note-taking conventions that make a coding agent useful long-term
- Output-format contracts (tables, JSON, step-by-step) that survive real use
