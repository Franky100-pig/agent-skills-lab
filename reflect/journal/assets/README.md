# journal/assets/

Screenshots, charts, and other images referenced by journal notes.

Convention: name files `<date>_<short-topic>.png`, e.g.
`2026-10-03_agent_burying_answer.png`, and embed from a note with:

```markdown
![agent burying the answer](assets/2026-10-03_agent_burying_answer.png)
```

Keep images small (screenshots, not photos) — this repo loads fast for
everyone who browses it.
